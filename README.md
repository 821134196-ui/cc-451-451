# 自助证件照门店拍摄重选与取件系统

门店自助证件照全流程模拟：叫号 → 锁定拍摄设备 → 规定轮次内重拍 → 候选选片确认 →
裁切 →（人工修正）→ 冲印 → 取件码核验；含加印与误操作退款。零第三方依赖，
仅使用 Python 3 标准库 + SQLite + SVG 占位素材。

## 一条命令启动

```bash
./run.sh          # 默认 8000 端口，可带参数 ./run.sh 8124
```

首次启动自动完成初始化：SQLite 建表（`data/idphoto.db`）、生成 12 张预置占位人像
（`data/placeholders/`）、种子两台拍摄亭与两台冲印机。打开 <http://127.0.0.1:8000>。

## 八个交付页面

| 页面 | 地址 | 说明 |
| --- | --- | --- |
| 叫号屏 | `/screen/call` | 在处理订单、设备锁定状态、最近完成 |
| 拍摄终端 | `/screen/capture` | 排队号进入、拍摄/重拍，**按钮固定屏幕下方**，可模拟眨眼 |
| 候选选择 | `/screen/select` | **同尺寸网格、无滤镜**；双终端确认只接收首个版本；店员重开必须写原因 |
| 规格预览 | `/screen/preview` | **毫米尺寸 + 裁切安全线**、头高/顶距测量、裁切微调与越界测试 |
| 修正队列 | `/screen/retouch` | 修图人员视图，**不含付款明细**，提交修正版转待冲印 |
| 冲印任务 | `/screen/print` | 执行冲印、缺纸/卡纸模拟、后台重试、创建加印（关联原任务） |
| 取件核验 | `/screen/pickup` | **仅大号数字键盘 + 结果提示**，过期/失效明确提示 |
| 退款复核 | `/screen/refund` | 店员发起（必填原因）→ 店长审核 → 模拟付款通道退回，幂等 |

首页 `/` 可叫号开单（模拟付款回执）、切换设备离线/缺纸、纵览全部订单。

## 状态机与关键规则

```
queued(拍摄中) ──确认选片──▶ selected/retouching ──修正完成──▶ printing
  └──────────────▶ printing ──冲印 done──▶ completed ──核验──▶ picked
任意未取件状态 ──店长审核退款──▶ cancelled（未完成冲印任务作废、释放设备）
```

- **设备锁**：叫号即锁定拍摄设备（`devices.locked_by`），离线不能叫号；拍摄中途离线
  保持锁定、拒绝拍摄，恢复后继续；确认/退款后释放。
- **轮次**：每单最多 3 轮（`MAX_ROUNDS`），眨眼片现场标记并建议重拍，到轮次上限必须选定。
- **确认竞态**：`BEGIN IMMEDIATE` 串行化，只有首个确认成功，第二台终端收到
  `already_confirmed`，并展示已生效版本。
- **规格校验**：按毫米测量头高与头顶留白；不符合的候选允许确认但强制进入人工修正。
  裁切框移出原始画面返回 `crop_out_of_bounds`。
- **冲印/加印**：缺纸任务置 `failed_no_paper`，后台每 5 秒重试、最多 3 次，加纸后自动完成；
  已冲印（存在 done 任务）的订单**不能改选原片**，只能创建加印任务，加印以
  `parent_job_id` 关联原冲印任务，且不改变订单状态。
- **取件码**：冲印完成自动签发 6 位码，24 小时有效（`PICKUP_CODE_TTL`）；后台扫描置失效，
  店员可重新签发。
- **退款**：幂等键（订单+金额+发起人）防重复申请，UNIQUE 约束兜住并发；必须店长审核；
  通道瞬时失败保持 pending 可重试，通道侧与库表双重保证不重复打款。
- **权限**：修图人员接口 DTO 剔除金额/付款状态/回执字段，并写 `retouchers_view_log` 审计。

## 进程内任务

`app/worker.py` 守护线程每 2 秒扫描：取件码到期失效；每 5 秒重试可重试的打印任务。
冲印页“立即执行后台扫描”按钮可手动触发（`POST /api/worker/tick`）。

## 模拟适配器（`app/adapters.py`）

- `MockCamera`：确定性产出 6 种占位人像变体（变体 5 头大，触发规格不符），可切眨眼模式。
- `MockPrinter`：按设备状态/纸张判定成功或缺纸，可注入卡纸失败。
- `MockPayment`：付款返回回执号，退款按回执打款并在通道侧防重，可模拟超时。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

20 个用例覆盖：**设备锁、确认竞态（真实双线程）、规格校验、加印关联、退款幂等**，
另含眨眼重拍/轮次上限、裁切越界、缺纸后台重试、取件码失效与重签、修图权限脱敏、
通道超时重试等路径。
